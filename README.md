# 🏠 UK Roofing Cost Estimator & Quoting Tool

[![Live Demo](https://img.shields.io/badge/Live%20Demo-Netlify-00C7B7?style=for-the-badge&logo=netlify&logoColor=white)](https://roofingapex.netlify.app/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg?style=for-the-badge)](https://opensource.org/licenses/MIT)

An interactive, responsive 4-step ballpark cost estimator built for UK roofing contractors. Helps homeowners get an instant preliminary estimate in 45 seconds while capturing high-intent inquiries directly for sales teams.

## ⚡ Key Features
- **Multi-Step Calculation Engine:** Pitch selection (Gable, Hip, Flat), area in square meters (^2$), and material tiers (Slate, Tiles, GRP/Felt).
- **Dynamic Ballpark Pricing:** Calibrated to current UK trade labor and material averages.
- **Lead Capture & Verification:** Built-in UK postcode validation and contact capture form.
- **Zero-Dependency:** 100% client-side vanilla JavaScript and Tailwind CSS.
- **Embeddable:** Compatible with WordPress, Wix, Webflow, and Squarespace via 1-line iframe or script.
